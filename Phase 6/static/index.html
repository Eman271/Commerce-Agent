Evaluation on the labelled conversations

The harness replays all 172 labelled conversations from conversations.json against a fresh database each time and compares the agent's final action and escalation decision with the labels. Run it live and the numbers are recomputed from the same conversations, right in front of you.

Concurrency test: can two customers oversell the last unit?

Simulated customers race to reserve the same variant at the same moment. Stock reservation is one atomic database update, so the total reserved can never exceed the stock on hand.

Trained model (Deliverable 6 model file)

TF-IDF + Logistic Regression intent classifier, trained on the 120 dev conversations (train_model.py → models/intent_model.pkl). In the live agent it is only a fallback signal.
